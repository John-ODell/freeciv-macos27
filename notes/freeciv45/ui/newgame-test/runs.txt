## Run 1: empty HOME, no options file. The launcher passes -t; the client saves the tileset it loaded.
== main  turn 0  title "Freeciv45"  tileset freeciv45iso  ruleset ""
== pregame  turn 0  title "Freeciv45"  tileset freeciv45iso  ruleset "Freeciv45 ruleset"

## Run 2: same HOME, the options file from run 1. No -t; the saved freeciv45iso and civ45 again.
== main  turn 0  title "Freeciv45"  tileset freeciv45iso  ruleset ""
== pregame  turn 0  title "Freeciv45"  tileset freeciv45iso  ruleset "Freeciv45 ruleset"
== ingame  turn 1  title "Freeciv45"  tileset freeciv45iso  ruleset "Freeciv45 ruleset"

   ps: freeciv-server -p 5557 --bind localhost -q 1 -e --saves <home>/.freeciv/saves --scenarios <home>/.freeciv/scenarios -A none --ruleset civ45
